QUICK START
=====================================
1. cd laravel-fsm-phase1
2. composer install
3. npm install
4. cp .env.example .env
5. Configure database in .env
6. php artisan key:generate
7. php artisan migrate --seed
8. npm run build
9. php artisan serve
10. Visit http://localhost:8000
